# TikTok — автопостинг про фильмы

Автоматизация, которая раз в 2 дня публикует в TikTok фото-пост на тему
фильмов: подбирает тему, пишет список фильмов, подпись и хэштеги, накладывает
текст на одно из базовых фото и публикует через TikTok.

## Как это работает

- Публикация идёт через Higgsfield MCP (`tiktok_prepare_publish` /
  `tiktok_publish`) — он служит мостом к TikTok API для уже подключённого
  аккаунта, без своего OAuth-приложения.
- Раз в 2 дня срабатывает Routine (запланированный триггер), который проходит
  пайплайн из [`automation/PIPELINE.md`](automation/PIPELINE.md).
- Тексты (тема, список фильмов, подпись, хэштеги) пишет модель на лету — не
  хранятся заранее, только пул тем в [`automation/themes.json`](automation/themes.json).
- Картинка не генерируется ИИ: текст накладывается на одно из твоих
  собственных базовых фото ([`automation/base_images.json`](automation/base_images.json))
  через [`automation/compose_post.py`](automation/compose_post.py) (Pillow).
- История опубликованного — в [`automation/posts_log.json`](automation/posts_log.json),
  используется чтобы не повторять тему/фото/фильмы подряд.

## Файлы

| Файл | Назначение |
|---|---|
| `automation/PIPELINE.md` | Пошаговая инструкция для каждого запуска |
| `automation/themes.json` | Пул тем про фильмы |
| `automation/base_images.json` | Ссылки на базовые фото (заполняется после загрузки) |
| `automation/posts_log.json` | История постов (тема/фото/фильмы, чтобы не повторяться) |
| `automation/config.json` | Настройки публикации и анти-повторов |
| `automation/compose_post.py` | Наложение заголовка и списка фильмов на фото |
| `automation/fonts/` | Шрифты для наложения текста (с поддержкой кириллицы) |

## План развития (фаза 2)

Сейчас темы просто ротируются без обратной связи. Планируется подключить
анализ просмотров/охватов и (по возможности) комментариев через собственное
приложение в TikTok for Developers, чтобы следующая тема выбиралась на основе
того, что реально заходит аудитории. Это требует верифицированного домена под
OAuth redirect и прохождения ревью TikTok — отдельный этап, не блокирующий
текущую версию.
